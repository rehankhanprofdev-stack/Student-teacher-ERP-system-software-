                                   CAMPUSOS // NEXT-GEN CAMPUS SYSTEM

I built a college management system from scratch: CampusOS 🎓

Most college portals I’ve seen are slow, cluttered, or locked behind expensive software. So I built a lightweight one for the Maulana Azad College Portal using plain PHP and MySQL, with no frameworks.

What it does:

👨‍🎓 Students see attendance and marks on a live dashboard. They also get “can miss 3 more classes” and “attend next 2” hints to stay above the 75% minimum. They can submit assignments and print their result card.

👩‍🏫 Teachers take attendance in one click (Present / Late / Absent), enter marks per exam, post and grade assignments, and publish notices. They only see their own subjects.

🛠️ Admins manage users, courses, subjects and teacher assignments, and can generate printable reports (attendance, marks sheets, defaulters) with CSV export.

Under the hood:

PHP 8.1+ and MySQL, with custom CSS
Automatic attendance %, grades and pass/fail calculation
PDO prepared statements, hashed passwords, CSRF protection, role-based access and login lockout after repeated failures
A one-click installer with demo data, and it runs free on shared hosting

Building it taught me a lot about database design, access control and designing for three very different kinds of users.
